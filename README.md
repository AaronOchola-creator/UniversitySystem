# University Department Information System

## Project Description
This project models a university department using Java concepts.  
It includes classes for Students, Professors, Courses, Admin Staff, and Departments.  
The system demonstrates encapsulation, inheritance, method overriding, and dynamic input handling.

## Dynamic Input
- Users can enter student, professor, and course details at runtime using the console and the grades are entered dynamically instead of being hardcoded.

## Exception Handling
- Number Format Exception: Caught when a user enters non-numeric input for grades.
- General Exception: Catches unexpected runtime errors to prevent program crashes.
- Finally block: Ensures resources (Scanner) are closed safely.
